# AI Cinematic Production — Skills Roadmap

نبني الـ skills واحدة واحدة. كل skill مبنية على اللي قبلها.

| # | Skill | الحالة | الهدف |
|---|---|---|---|
| 1 | `cinematic-shot` | ✅ جاهزة | لقطة سينمائية واحدة بدون تشوه (الأساس لكل حاجة) |
| 2 | `scene-sequence` | ⏳ | مشهد كامل من كذا لقطة بنفس الشخصية والإضاءة والألوان (continuity) |
| 3 | `real-plate-shooting` | ⏳ | إزاي تصور الشخص الحقيقي صح (إضاءة، كاميرا ثابتة، clean plate) عشان الـ AI يشتغل عليه |
| 4 | `anchor-to-virtual-world` | ⏳ | المذيع يخرج من الاستوديو لعالم افتراضي — hybrid: تصوير حقيقي + AI + كومبوزيت |
| 5 | `graphics-around-talent` | ⏳ | جرافيك وموشن حوالين الشخص الحقيقي (tracking, depth, light wrap) |
| 6 | `finishing-grade` | ⏳ | upscale + deflicker + grade + grain موحد عشان الشغل يبان "متصور" مش "متولد" |
