# AI Cinematic Production — Skills

نبني الـ skills واحدة واحدة. كل skill مبنية على اللي قبلها.
الافتراضي الثابت: **16:9**. باقي المدخلات بتتسأل في أول كل مشروع.

## قواعد المستخدم (بتكسب في أي تعارض)
| Skill | الدور |
|---|---|
| `look-style-system` | اللوك (Depth/Edge/Grade/Detail) + LUT للتون + ألوان من الـ reference + ممنوع dissolve + ممنوع لوك بلاستيك + الكاميرا من فيديو reference + ممنوع موسيقى |
| `scene-continuity` | كروت الشخصيات والمكان والوقت، ومفيش شخصية مكررة، واتجاه الضوء ثابت |
| `historical-accuracy-check` | مراجعة أي معلومة حقيقية من مصادر، ومن غير تخمين |
